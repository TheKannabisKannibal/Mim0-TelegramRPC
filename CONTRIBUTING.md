# Contributing to Mim0

Thanks for helping improve Mim0.

## Before opening an issue

- Make sure you are using the latest GitHub Release.
- Check the README troubleshooting section.
- Reproduce the issue with Discord Desktop running.
- Use the tray menu's diagnostics option when reporting bugs.

## Pull requests

1. Keep changes focused.
2. Do not commit secrets, Discord tokens, personal data, `bin/`, or `obj/`.
3. Test the application on Windows 10/11 x64.
4. Run `build.bat` before opening a PR.
5. Explain what changed and how you tested it.
