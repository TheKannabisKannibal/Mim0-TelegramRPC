# Changelog

## [1.3.0] - 2026-08-17

### Added
- GitHub Releases update checker on application startup.
- One-click download and launch of the latest Inno Setup installer.
- Update prompts remember the offered version so the same release is not shown repeatedly.

## [1.2.0] - 2026-08-17

### Added
- Settings window with Rich Presence templates.
- Telegram-only and all-media-session modes.
- Album art, progress, pause and Windows startup controls.
- Discord reconnect and diagnostics.
- Improved system tray controls.
- Portable ZIP and Inno Setup installer.

### Fixed
- Windows Media Session detection.
- Discord IPC reconnect handling.
- Tray application lifecycle.
- Build and installer configuration.
